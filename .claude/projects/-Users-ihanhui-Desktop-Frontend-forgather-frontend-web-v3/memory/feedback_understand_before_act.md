name: 지시를 정확히 이해하고 실행
description: "이름 바꿔", "디렉토리 정리해" 같은 요청은 반드시 현재 구조를 먼저 파악하고 사용자 의도를 확인한 뒤 실행한다.
type: feedback
---

단순해 보이는 요청도 현재 상태를 먼저 파악하고 의도를 정확히 이해한 뒤 실행한다.

**Why:** "이름만 바꾸라고"를 오해해서 디렉토리 안의 컴포넌트 이름을 바꿨는데, 실제 의도는 상위 디렉토리명 변경이었다. 잘못 이해한 채 커밋까지 해버려서 revert/reset을 반복하는 상황이 생겼다.

**How to apply:** 디렉토리 구조 변경 요청 시 `ls`로 현재 구조를 먼저 확인하고, 어떤 파일/디렉토리를 어떻게 바꿀지 한 줄로 정리해서 확인 후 실행한다. 불명확하면 먼저 물어본다.

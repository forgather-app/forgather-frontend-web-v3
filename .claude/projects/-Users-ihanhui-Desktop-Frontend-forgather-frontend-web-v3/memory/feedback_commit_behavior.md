---
name: 커밋은 /commit 스킬 호출 시에만
description: 사용자가 명시적으로 /commit을 호출할 때만 커밋한다. 작업 중간에 임의로 커밋하지 않는다.
type: feedback
---

커밋은 반드시 사용자가 `/commit`을 명시적으로 호출할 때만 실행한다.

**Why:** 작업 흐름 중간에 임의로 커밋해서 사용자가 원치 않는 커밋이 생겼다. revert/reset 작업 후 복구하면서도 사용자 승인 없이 커밋을 실행했다.

**How to apply:** 파일 수정, 디렉토리 구조 변경, revert/reset 등 어떤 작업이든 커밋은 절대 자동으로 하지 않는다. 사용자가 `/commit`을 입력할 때까지 기다린다.

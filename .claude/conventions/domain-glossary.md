# forgather 도메인 용어집

화면에 보이는 이름과 코드 식별자가 다른 경우가 많아서 정리한 표입니다.
PR 본문, 이슈, 커밋, 문서처럼 사람이 읽는 글에서는 **화면 표기**를 쓰고, 코드를 가리킬 때만 식별자를 백틱으로 씁니다.

> 이 파일은 손으로 관리합니다. 화면 문구가 바뀌거나 새 용어가 생기면 같은 PR에서 이 표도 고쳐 주세요.
> 표에 없는 용어는 해당 페이지 컴포넌트에서 화면 문자열을 직접 확인합니다 (`git grep -n "문구" -- src/pages src/components`).

## 핵심 개념

| 화면 표기 | 코드 식별자 | 비고 |
| --- | --- | --- |
| 스페이스 | `Space`, `space-스페이스` API | 작가가 자기 전시·작품을 모아 두는 공간. 스페이스명, 스페이스 소개 |
| 전시 | `Exhibition`, `exhibition-전시` API | 스페이스에 속한 전시 정보 |
| 작품 | API는 `Product`(`product-전시-작품`), 페이지·라우트는 `artwork` | 같은 대상을 코드에서 두 이름으로 부른다. 글에서는 항상 "작품" |
| 방명록 | `GuestBook`, `GuestBookCard`, `guestbook-방명록` API | 방문자가 스페이스에 남기는 카드 |
| 작가 / 작가님 | `Host`, `host-호스트` API | 화면에서는 "작가(님)"으로 부른다. "호스트"는 코드·API에서만 |
| 작가 화면 | `guest*`가 아닌 페이지 (`space`, `guestBook`, `artwork` 등) | 로그인한 스페이스 주인이 보는 화면. "방문자 화면"과 짝으로 쓴다 |
| 방문자 | `guest*` 페이지·컴포넌트 (`guestSpace`, `guestGuestBook`, `GuestHeader` 등) | 스페이스 주인이 아닌 사람이 보는 화면. 화면에 직접 찍히는 말은 없고, 코드 주석은 "게스트"라고 쓴다. 글에서는 "방문자 화면"으로 통일 |
| 스페이스 홈 | 작가 화면 `ArtworkPage`, 방문자 화면 `GuestArtworkPage` | 스페이스에 들어가면 처음 보이는 화면. 화면 문구는 아니고, 폴더명 `artwork` 때문에 "작품 페이지"로 부르기 쉬우니 주의. 상단 "작품"/"방명록" 탭으로 전환 |
| 스페이스 소개 / 더보기·접기 | `isDescriptionExpanded`, `useIsTruncated` | 스페이스 홈의 소개글. 길면 "더보기" 버튼으로 펼치고 "접기"로 닫는다. 작가 화면 오른쪽 위 세로 점 3개 메뉴 버튼도 `aria-label="더보기"`라 글에서는 "소개 더보기"와 "더보기 메뉴"로 구분 |
| 마이페이지 | `myPage` | 하단 탭 표기는 "마이" |
| 약관 | `Term`, `term-약관` API | 온보딩 약관 동의, 재동의 |

## 상태·플래그

| 화면 표기 | 코드 식별자 | 비고 |
| --- | --- | --- |
| 진행 등록 / 진행 해제 | `space.isFeatured` | `progressStatus`와 다른 개념. 홈의 "지금 축하받는 스페이스"에 노출되는지 여부 |
| 진행중 / 종료 (예정) | `ExhibitionResponseProgressStatus` (`IN_PROGRESS`, `ENDED`, `UPCOMING`) | 전시 기간 기준 상태 |
| 방명록 나만 보기 | `space.isPublic === false`, 폼에서는 `isGuestBookPrivate` | 값이 반대다. 나만 보기 켜짐 = `isPublic: false` |
| 새로 도착한 방명록 / NEW 배지 | 방명록 카드의 `isRead === false`, `GuestList`의 NEW variant | 작가가 아직 읽지 않은 방명록. 글에서는 "새로 도착한 방명록"으로 통일하고 "안 읽은 방명록"은 쓰지 않는다 |
| 읽음 처리 | 방명록 상세 조회 API | 상세를 조회하면 서버가 읽음으로 바꾼다. 화면 문구는 아니지만 PR에서는 이 이름으로 부른다 |

## 표기 규칙

- "포게더" — 서비스 이름. 영문이 필요할 때만 `forgather`
- "작품 사진", "첨부한 사진" — 방명록에 붙인 이미지는 "첨부한 사진"
- 영문 병기는 하지 않습니다. "방명록(GuestBook)"처럼 쓰지 말고 화면 표기 하나만 씁니다.
